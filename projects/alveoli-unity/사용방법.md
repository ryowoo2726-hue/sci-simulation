# 허파꽈리 기체 교환 3D

## 실행

1. Unity Hub에서 **Add → Add project from disk**로 이 `UnityAssets` 폴더를 등록합니다.
2. **Unity 6000.3.27f1**로 엽니다. Universal RP 17.3.0 패키지 다운로드가 필요합니다.
3. 첫 임포트가 끝나면 전용 씬과 렌더 파이프라인이 자동 설정됩니다.
4. **Play**를 누릅니다. 자동 설정이 실행되지 않으면 상단 **Alveoli → Create or rebuild simulation scene**을 선택합니다.

씬: `Assets/LungGasExchange/Scenes/AlveolarGasExchange.unity`.
모델은 Play 시 메시로 생성되므로 편집 모드의 빈 씬은 정상입니다.

## 조작

- 드래그: 회전, 휠: 확대/축소, R: 시점 복원.
- Space 또는 화면 버튼: 일시정지/재생. 속도 슬라이더: 0.2–2배.
- 외형/절개, 장벽 확대, 기체 표시, 분압 같게 비교 버튼을 제공합니다.
- `처음부터`는 시간·재생 속도·분압 비교를 초기화합니다.

## 활용한 폴더 내 자료

- `LivingTissue.shader`: 젖은 조직 광택, 표면 미세결, 투과광 근사와 절개.
- `AnatomyGhost.shader`: 내부 적혈구를 볼 수 있는 투명 모세혈관 외벽.
- `HeartGeometry.cs`: 곡선·메시 생성.
- `ReferenceSource/SplineBloodFlowController.cs.txt`: 양면 오목 적혈구 형상.
- 기존 O2/CO2 SDF 데이터: Resources에 원본을 복사하고 실제 원자 좌표를 읽어 분자 생성.
- Noto Sans KR 폰트와 기존 URP 렌더러/파이프라인.
- 허파꽈리 모델링 도안과 생체 표현 명세: 새 절개 폐포·모세혈관망 구성 참고.

폴더에 완성 FBX/프리팹은 없어 폐포낭·혈관망·적혈구·장벽은 코드로 메시를 생성했습니다. PDB 헤모글로빈 파일은 보존했으며 분자 단위 헤모글로빈 렌더링에는 사용하지 않았습니다.

## 과학적 표현 범위

O2는 폐포 공기에서 혈액으로, CO2는 혈액에서 폐포 공기로 순이동합니다. 분압 평형 비교에서는 방향 화살표와 순이동을 멈추고 무작위 운동을 유지합니다. 안정 시 대표 분압 O2 100/40, CO2 40/46 mmHg를 사용합니다. 혈액은 어두운 적색에서 선홍색으로 변합니다.

교육용 모형입니다. 메시 구조, 조직층 두께, 분자 크기·수·색, 호흡 변형과 시간은 시각화를 위해 단순화했습니다. 분압 차는 고정된 설명값이며 혈류-환기 결합 또는 실제 확산계수를 풀어 계산하는 생리학 해석기는 아닙니다. 분압 평형 비교는 양쪽 분압을 같게 둔 별도 조건입니다. 장벽과 주변 허파꽈리는 해부학 스캔을 재구성한 모델이 아닙니다.

근거: [NHLBI — 호흡의 기능](https://www.nhlbi.nih.gov/health/lungs/breathing-benefits), [NCBI — 폐 환기와 관류](https://www.ncbi.nlm.nih.gov/books/NBK539907/).

## 검증과 빌드

`powershell -ExecutionPolicy Bypass -File .\Tools\Check-Compilation.ps1`로 C# 컴파일을 확인할 수 있습니다.

Unity 라이선스가 활성화된 환경에서 다음 명령을 실행합니다.

```powershell
& 'C:\Program Files\Unity\Hub\Editor\6000.3.27f1\Editor\Unity.exe' -batchmode -quit -projectPath $PWD -executeMethod BuildAlveoli.Build -logFile build.log
```

결과는 상위 폴더 `Alveoli-Windows/Alveoli.exe`입니다. 실행 파일에 `-verify` 인수를 붙이면 분자 원자 수, 확산 방향, 평형 조건, 시계 진행·일시정지, 평형 시 화살표 숨김을 검사하고 `Verification`에 두 화면을 캡처한 뒤 종료합니다. 완료 시 `checks.txt`와 로그의 `ALVEOLI_VERIFICATION_PASS`로 확인합니다.

현재 작업 환경에서는 Unity의 `No valid Unity Editor license found` 오류로 프로젝트 임포트·셰이더 컴파일·Play 화면·Windows 빌드를 검증하지 못했습니다. 설치된 Unity 어셈블리를 사용한 C# 소스 컴파일만 별도로 검증했습니다. 따라서 실사 표현의 최종 품질과 화면 배치는 실제 Play 화면 확인이 필요합니다.
