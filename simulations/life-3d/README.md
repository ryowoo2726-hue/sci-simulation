# 생명 구조 탐구실

동물세포·근육 조직·심장을 한 화면에서 선택하고 회전·확대하며 구조를 배우는 정적 웹사이트입니다. 도안을 참고해 재구성한 기본 모형을 Blender 5.2에서 다듬어 GLB로 내보냈습니다. 구조 이해를 위한 교육용 모형으로, 해부학 구조의 크기와 배치는 단순화되어 있습니다.

## Blender 개선판

현재 웹페이지는 고해상도 개선판(`*-hq.glb`)을 사용합니다. 각 모형에 1024px 색상·거칠기·노멀 텍스처를 포함하고, 웹에서도 환경 조명과 부위 사이 그림자를 사용합니다. 모형 하나를 처음 불러올 때 약 19~23MB를 내려받습니다.

- 심장: 비대칭 외형, 두께가 있는 절개면, 오목한 네 방, 판막의 얇은 막과 힘줄끈·유두근, 외부 관상혈관을 표현했습니다.
- 세포: 불규칙한 세포막과 겹친 소포체·골지체, 핵 내부 염색질, 리보솜 입자를 보강했습니다.
- 근육: 섬유의 미세한 결, 근절의 띠, 결합 조직의 콜라겐을 보강했습니다.
- 렌더링과 GLB의 색·거칠기·표면 요철은 동일한 텍스처를 사용합니다. 조명 차이로 밝기와 반사는 다를 수 있습니다.
- 도안을 참고해 제작한 시각화입니다. 생물학적 구조를 설명하기 위한 색과 배치를 사용합니다.

- 동물세포: 두께가 있는 소포체·골지체 막, 가지 친 매끈면 소포체, 절개 미토콘드리아와 크리스타, 핵막의 핵공 표현
- 근육 조직: 근원섬유 길이 방향의 섬유, 단면의 필라멘트, 근소포체 연결망, 결합 조직 섬유
- 심장: 오목한 네 방, 두께를 구별한 심근 테두리, 속이 빈 혈관, 심실 안쪽의 융기
- 각 구조의 부위 ID를 GLB에 저장하여 기존 43개 설명과 연결합니다.
- GLB를 내려받지 못하면 기본 모형으로 탐구할 수 있습니다.
- 편집용 cell-hq.blend, muscle-hq.blend, heart-hq.blend는 별도의 Blender 원본 압축 파일에 있습니다. 웹 배포에는 assets/models의 GLB만 필요합니다.

## 실행

Node.js가 설치된 컴퓨터에서 이 폴더를 터미널로 열고 `npm start`를 실행한 다음 http://127.0.0.1:4173 에 접속하세요. npm install은 필요하지 않습니다. 모듈 파일 때문에 index.html을 더블 클릭하는 방식은 지원하지 않습니다.

## 통합 포털

이 탐구실은 sci-simulation 저장소의 `simulations/life-3d/`에 통합되어 있습니다. 저장소 최상위 index.html의 생명 구조 카드에서 열고, 탐구실 상단의 ‘전체 시뮬레이션’으로 돌아갑니다. `?model=cell`, `?model=muscle`, `?model=heart`로 시작 모형을 지정할 수 있습니다.

## GitHub Pages 배포 (단독으로 사용할 때)

1. GitHub에서 새 저장소(예: `life-structure-3d`)를 만듭니다. GitHub Free의 경우 공개 저장소를 사용합니다.
2. **이 README가 있는 science-3d 폴더 안의 내용**을 저장소의 최상위에 올립니다. index.html이 최상위에 있어야 합니다. node_modules 폴더는 제외합니다.
3. 저장소의 Settings → Pages → Build and deployment에서 Source를 Deploy from a branch로 선택합니다.
4. Branch를 main, 폴더를 /(root)로 선택하고 Save합니다.
5. 배포가 끝나면 표시되는 `https://사용자이름.github.io/저장소이름/` 주소를 학생들에게 공유합니다.

별도 서버·API 키·로그인이 필요하지 않습니다. 라이브러리도 vendor에 포함되어 외부 CDN에 의존하지 않습니다. 학생의 활동 정보를 수집하거나 저장하지 않습니다.

## 사용법

- 상단에서 동물세포, 근육 조직, 심장을 선택합니다.
- 마우스 드래그 또는 한 손가락으로 회전하고, 휠 또는 두 손가락으로 확대합니다.
- 마우스를 올리면 부위 명칭이 나타나고 클릭 또는 터치하면 설명이 고정됩니다.
- 오른쪽 부위 목록은 키보드와 터치로도 사용할 수 있습니다. 선택 부위는 색이 밝아지고 이름표가 표시됩니다.
- 명칭 표시: 화면 공간에 맞게 겹치지 않는 이름표를 표시합니다. 전체 명칭은 부위 목록에서 확인합니다.
- 내부 보기: 절개면을 열고 닫습니다. 목록에서 내부 부위를 선택하면 자동으로 열립니다.
- 처음 방향, 자동 회전, 전체 화면, 원본 도안 보기 기능을 제공합니다.

## 교사용 안내

- 기본 정면에서 심장의 해부학적 오른쪽은 화면 왼쪽입니다.
- 심장의 파랑·빨강은 산소가 적고 많은 혈액을 구별하는 학습 표현입니다. 실제 혈액은 모두 붉습니다.
- 심장 표면·내부, 세포 소기관, 근육 구조는 학습을 위해 크기·형태·위치가 단순화되어 있습니다. 혈류·심박·근수축 애니메이션은 포함하지 않았습니다.
- 세포(동물세포), 조직(근육 조직), 기관(심장)은 구조 수준을 비교하기 위한 예입니다. 이 골격근 모형이 심장근으로 이어지는 계통을 뜻하지 않습니다.
- 근육 모형은 골격근 섬유 한 개의 확대 모형입니다. 골격근 섬유는 여러 핵을 가진 긴 세포이며 여러 근섬유가 모여 근육 조직을 이룹니다.

## 파일

- index.html / style.css: 화면 구성
- app.js: 조작·부위 선택·설명 표시
- models.js: 부위가 분리된 3D 구조
- refined-models.js: Blender GLB 불러오기·부위 ID 연결
- assets/models/: Blender에서 내보낸 웹용 모형 3개
- data.js: 한국어 명칭·영어 명칭·위치·기능 (직접 수정 가능)
- references/: 제작에 참고한 원본 도안
- vendor/: Three.js 0.186.1, OrbitControls, GLTFLoader 및 유틸리티, MIT 라이선스
- serve.cjs: 로컬 미리보기 서버

GitHub Pages는 정적 호스팅입니다. 외부에서 접속할 수 있는 배포 주소는 저장소에 업로드하고 Pages 설정을 완료한 뒤 생성됩니다.
