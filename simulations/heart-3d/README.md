# 심장과 혈액의 길 · Unity WebGL

Unity 6000.3.27f1 / URP 17.3.0으로 만든 웹 빌드입니다. 심장 아틀라스의 단면과 네 판막, 12단계 혈류 따라가기, 자유 관찰과 여섯 개의 확인 문제를 제공합니다. 혈액·혈관 페이지에서 나란히 보거나 한 화면을 크게 볼 수 있습니다.

- 모델은 Z-Anatomy / BodyParts3D의 CC BY-SA 4.0 변형입니다. 출처, 변경 사항, 원본 모델의 이용 조건은 `ATTRIBUTION.txt`와 `Z-Anatomy-LICENSE.txt`를 보세요.
- 한글은 프로젝트에 포함된 Noto Sans KR 부분 글꼴을 사용합니다. 라이선스는 `NotoSansKR-LICENSE.txt`입니다.
- 심장 판막과 혈류는 학습용 애니메이션이며 정량 유체 계산이 아닙니다. 산소 교환은 심장 밖의 폐와 몸에서 일어난다고 안내합니다.
- gzip과 Unity의 압축 해제 대체 기능을 사용합니다. GitHub Pages에서 별도의 압축 HTTP 헤더 없이 실행할 수 있습니다.

## 수정과 다시 빌드

### 웹 최적화와 확인

편집용 미리보기 메시와 실행용 아틀라스를 중복 배포하지 않도록 WebGL 전용 시작 장면을 사용합니다. 전송 파일 합계는 최적화 전 15,612,975바이트에서 11,910,815바이트로 약 24% 감소했습니다. 모델의 정점 수는 유지했습니다. 판막 개폐가 변하지 않으면 메시 재계산을 건너뛰고, 혈류 정렬 목록을 재사용합니다. 브라우저 렌더 해상도는 기기 픽셀 비율 1.5로 제한합니다.

`node simulations/heart-3d/check-web.cjs`로 화면 전환, 휴대전화 초기 단일 화면, 선택 시 로딩, gzip 데이터 및 WebAssembly 헤더와 라이선스 파일을 검사합니다. Unity 빌드는 판막 위상·혈류 게이트·12개 학습 단계·퀴즈·경로·셰이더 검증을 통과했습니다. 이 검사는 실제 브라우저의 그래픽·조작 검증을 대신하지 않습니다.

`source/`는 실행판에 사용한 Unity C# 스크립트, 셰이더, 아틀라스 데이터, 부분 글꼴, 패키지 목록 및 편집용 Blender 모델을 포함합니다. Unity 6000.3.27f1에 WebGL Build Support를 설치하고 `source` 폴더를 프로젝트로 연 후 `Heart > Build WebGL`을 실행하세요. 이 명령은 장면·프리팹과 `Build/HeartWeb`을 생성하며 위상·혈류·단면·학습 데이터 검증을 수행합니다. 생성된 `Build/HeartWeb/Build`의 파일을 이 페이지의 `Build` 폴더에 복사합니다.

Blender 모델을 수정한 경우 `source/Tools/export_edited_atlas.py`로 아틀라스 데이터도 다시 생성할 수 있습니다. 모델 좌표는 원본 축과 미터 단위를 유지해야 합니다. 공개 모델의 제작자 표시와 동일한 공유 조건을 유지하세요.
