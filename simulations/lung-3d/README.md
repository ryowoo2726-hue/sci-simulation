# 폐와 허파꽈리 3D 탐험

`index.html`을 정적 웹 서버에서 열면 실행됩니다. Three.js와 OrbitControls는 `vendor/`에 포함되어 있습니다.

- 폐·기관·기관지·허파꽈리 선택, 회전·확대, 호흡 일시 정지 및 겉면 표시를 지원합니다.
- 교육용으로 구조와 크기를 단순화한 웹 모형입니다.
- 별도의 Unity 폐포 기체 교환 프로젝트 소스는 [`projects/alveoli-unity`](../../projects/alveoli-unity/)에 있습니다. Unity 프로젝트는 웹 실행용 빌드가 아닙니다.
